# Задание 3. Создание векторного индекса базы знаний

## Используемая эмбеддинг-модель

Для построения векторного индекса использована модель bge-m3.

| Параметр          | Значение                                |
| ----------------- | --------------------------------------- |
| Название модели   | BAAI / bge-m3                      |
| Размер эмбеддинга | 1024                                     |
| Язык              | Multi                                 |
| Ссылка            | https://huggingface.co/BAAI/bge-m3 |

## База знаний

Использована база знаний из предыдущего задания (преобразованная вселенная Dark Souls 1).

## Создание индекса

База знаний была преобразована в векторный индекс с использованием **FAISS**. 

Создание индекса осуществляется с помощью скрипта [build_index.py](./build_index.py) 

- количество чанков в индексе - 55
- общее время выполнения - 15 секунд
